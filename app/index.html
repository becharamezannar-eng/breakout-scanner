Shows the company, its earnings and a breakout and long-term view.

One-time setup on this phone (about 2 minutes). New analyses run on your GitHub account, so the app needs a key:

  1. Tap make a key on GitHub and sign in.
  2. Name: scanner app. Expiration: 1 year.
  3. Repository access: Only select repositories → breakout-scanner.
  4. Permissions → Repository → Actions → Read and write.
  5. Tap Generate token, copy it, come back and paste it here.
