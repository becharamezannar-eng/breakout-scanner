One-time setup for the Scan now button
  1. Open GitHub → new fine-grained token.
  2. Name it "scan button", set an expiry (up to 1 year).
  3. Repository access: Only select repositories → breakout-scanner.
  4. Permissions → Repository → Actions: Read and write. Nothing else.
  5. Generate, copy the token, paste it here and tap Save.

The token stays in this browser only. It can do nothing except start and read runs of this one repository. Without it, the buttons open GitHub's Run page instead.

How to read this

  • Look at AvgR (expectancy per trade, in units of risk) and ProfitFactor (gross wins / gross losses). Above 0 and above 1.0 respectively means an edge; the Gate-pass row should beat the Gate-fail row if the scorecard helps.
  • Small groups (under ~30 trades) are noise.
  • Limits: today's index members only (survivorship bias flatters results), no sector or earnings data in history (those score neutral), daily bars only (no intraday VWAP check), no commissions beyond slippage.
