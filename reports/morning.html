One-time setup for the Scan now button
  1. Open GitHub → new fine-grained token.
  2. Name it "scan button", set an expiry (up to 1 year).
  3. Repository access: Only select repositories → breakout-scanner.
  4. Permissions → Repository → Actions: Read and write. Nothing else.
  5. Generate, copy the token, paste it here and tap Save.

The token stays in this browser only. It can do nothing except start and read runs of this one repository. Without it, the buttons open GitHub's Run page instead.
