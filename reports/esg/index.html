One-time setup for the Scan now button
  1. Open GitHub → new fine-grained token.
  2. Name it "scan button", set an expiry (up to 1 year).
  3. Repository access: Only select repositories → breakout-scanner.
  4. Permissions → Repository → Actions: Read and write. Nothing else.
  5. Generate, copy the token, paste it here and tap Save.

The token stays in this browser only. It can do nothing except start and read runs of this one repository. Without it, the buttons open GitHub's Run page instead.

How companies qualify (UN standards)
  • UN Global Compact (human rights, labour, environment, anti-corruption): the indexes remove companies MSCI flags as UNGC violators.
  • Global exclusions: controversial and nuclear weapons, civilian firearms, tobacco, thermal coal, oil sands and other fossil-fuel ties (energy sector excluded), plus adult entertainment, alcohol, gambling, conventional weapons, nuclear power and palm oil, with revenue limits.
  • ESG quality: only companies with favourable MSCI ESG ratings stay in the index (the screen UN PRI signatory funds use).
  • UN SDGs: each company's line of business is linked to the goals it serves.
  • Breakouts, radar, scores, stops and targets use exactly the same rules as the main scanner.
